Ton agenda, ta prochaine chance, ta trajectoire

PITCH+ relie Hyperplanning, le syllabus et PITCH. Avant chaque séance : ce qu'il y a à démontrer. Pour chaque critère manqué : où le rattraper. Et où tu en es vers les 70 %.

Installation

Deux minutes, mode développeur

PITCH+ v7

Télécharge le zip et décompresse-le. Pas de Chrome Web Store pour l'instant.

Version 7.3.2

  1. Chrome → chrome://extensions → active Mode développeur (en haut à droite).
  2. Charger l'extension non empaquetée → choisis le dossier décompressé.
  3. Clique l'icône P+. Si PITCH demande une connexion, connecte-toi dans l'onglet ouvert puis « J'ai fini, relire ».
  4. Réglages ⚙ → colle ton lien d'abonnement iCal Hyperplanning (Exporter → Lien d'abonnement iCal).

Le lien iCal contient une clé secrète. Il reste sur ton ordinateur ; ne le partage pas.

Les trois écrans

Trois questions, trois réponses

AgendaChaque séance avec n à démontrer, m démontrés. TE et phases de PBL identifiés. Clic : les critères, l'acquis, la compétence, Moodle.
Prochaine chancePour chaque critère manquant : la prochaine séance datée, sinon le prochain cours du syllabus, sinon ⚠ requalification.
Trajectoire 70 %Démontré, daté, à venir, pas encore enseigné, perdu. Projection meilleur / pire cas. Par compétence, par semestre.
Hérité de v5Acquis avec filtres et notes, par cours, changements, CSV, impression.

Confirme toujours avec ton responsable de matière avant de t'inscrire à une requalification. Le verdict est une déduction, pas une décision officielle.
